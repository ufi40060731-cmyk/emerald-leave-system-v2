How updates work:
1. Edit files in this repository (or ask your assistant to).
2. Push to the `main` branch on GitHub.
3. Railway automatically rebuilds and redeploys within about a minute.

Local/offline use (optional):
Opening frontend/index.html directly from disk still works as a
no-backend demo (data stays only in the browser, not connected to the
real MySQL database) — useful for trying out the UI without deploying
anything. Do NOT use this mode for real employee data.
